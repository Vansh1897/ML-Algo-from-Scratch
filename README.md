# ML Algorithms From Scratch

Implementation of Machine Learning algorithms from scratch using Python, NumPy, and minimal external libraries to understand the mathematics and internal working of ML models.

This repository focuses on building algorithms manually instead of treating machine learning as:

```python
model.fit(X, y)
```

---

# Algorithms Implemented
- Linear Regression
- Ridge Regression(Regularization)
- Lasso Regression(Regularization)
- Logistic Regression
- Support Vector Classifier
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes
- Random Forest
- AdaBoost
- Gradient Boosting Regressor
- Gradient Boosting Classifier

# Tech Stack

- Python
- NumPy
- Pandas
- Scikit-learn (datasets and weak learners where required)

---

# Objectives

This project was built to:

- Understand ML algorithms mathematically
- Learn internal model mechanics
- Implement algorithms without abstraction-heavy libraries
- Strengthen problem-solving and coding skills
